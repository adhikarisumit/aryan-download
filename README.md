# Aryan – personal AI agent for Windows

Installer downloads and automatic updates for **Aryan**, sold by [digihub](https://digihubnepal.com/products/aryan-ai-agent).

Aryan needs a license key (lifetime, 1 PC) from digihubnepal.com and your own AI provider key (Anthropic, Gemini, OpenAI, Groq, xAI, OpenRouter) or a free local model with Ollama.
